Kasa - Projet d'Agence Immobilière 🏠

***************************************************************************************************************************
Présentation
***************************************************************************************************************************

Kasa est une application web moderne conçue pour faciliter la recherche de logements. 
Grâce à une interface intuitive développée avec React, Kasa permet aux utilisateurs de parcourir et de consulter des fiches 
détaillées de logements ainsi que des informations sur les propriétaires.

***************************************************************************************************************************
Fonctionnalités principales
***************************************************************************************************************************

🏡 Recherche de Logements : Parcourez une sélection variée de logements avec des filtres pour affiner la recherche selon les besoins de l'utilisateur.

📋 Fiches de Logements Détailées : Chaque fiche contient des informations complètes sur le logement (caractéristiques, photos, localisation) et des informations sur le propriétaire.

🌍 Interface Réactive et Dynamique : Développée en React, l'application offre une navigation rapide et fluide avec des mises à jour en temps réel des données sans rechargement complet de la page.

📱 Responsive Design : L'interface est parfaitement adaptée à tous les types d'appareils, garantissant une expérience utilisateur agréable sur mobile et desktop.

***************************************************************************************************************************
Technologies Utilisées
***************************************************************************************************************************

Front-end : React, JavaScript
Back-end : MongoDB pour la gestion des données
Outils de développement : Git, VSCode
